==================================================
1. CORE OBJECTIVE
==================================================

Build a professional, responsive, fast Dashboard/UI that acts as the bot's control center.

The Dashboard must:

- Display live market information.
- Display live MT5/Exness connection status.
- Display AI signals.
- Display SMC analysis.
- Display open trades.
- Display account information.
- Display trading performance.
- Display upcoming news.
- Display notifications.
- Display system/trading logs.
- Provide configuration/settings controls where already supported by backend.
- Provide safe control actions through existing backend APIs.

The Dashboard is a PRESENTATION + CONTROL layer.

The Dashboard MUST NOT:

- Generate trading signals itself.
- Perform independent market analysis.
- Calculate an alternative AI decision.
- Calculate an alternative risk decision.
- Directly call MetaTrader5 Python APIs.
- Directly connect to Exness.
- Bypass Risk Manager.
- Bypass Trade Manager.
- Implement a second authentication mechanism.
- Create fake market data to make the UI appear live.

All business logic must remain in backend modules.
