Official Section 3 requirements:

3.1 PURPOSE
The Market Data Engine must:
- Receive real market data from MT5/Exness
- Convert it into a standard format
- Provide market data to other modules
- Perform NO trading analysis itself

3.2 WORKFLOW

MT5/Exness
    ↓
Market Data Engine
    ├── Market Scanner
    ├── Technical Indicators
    ├── SMC Engine
    ├── AI Engine
    └── Dashboard

3.3 FEATURES

1. LIVE TICK DATA
Must provide:
- Bid
- Ask
- Spread
- Time

2. LIVE OHLC CANDLES
Each candle must contain:
- Open
- High
- Low
- Close
- Volume
- Time

3. MULTIPLE TIMEFRAMES
Required:
- M1
- M5
- M15
- M30
- H1
- H4
- D1

4. MULTIPLE CURRENCY PAIRS
Required:
- EURUSD
- GBPUSD
- USDJPY
- USDCHF
- AUDUSD
- USDCAD
- NZDUSD
- EURJPY
- GBPJPY
- EURGBP

5. HISTORICAL DATA
Must provide previous candles for:
- EMA
- RSI
- MACD
- ATR
- BOS
- Order Blocks
- AI Analysis

6. LIVE UPDATES
Must continuously handle:
- New candle detection
- Tick updates
- Price updates
- Fresh data for downstream modules

7. STANDARD DATA FORMAT
All modules should receive a consistent structure containing:
- Symbol
- Timeframe
- OHLC
- Volume
- Timestamp

8. DATA VALIDATION
Must detect/reject:
- Missing candles
- Invalid prices
- Wrong timestamps
- Duplicate candles
- Corrupted data

9. CONNECTION MONITORING
If MT5 disconnects:
- Detect disconnection
- Attempt reconnect
- Log errors
- Provide a mechanism for dashboard notification

10. PERFORMANCE
Must support:
- Fast operation
- Async operation
- Multiple pairs concurrently
- Multiple timeframes concurrently

3.4 DOWNSTREAM MODULES
Verify that data can be provided to:
- Market Scanner
- Technical Indicators
- SMC Engine
- AI Engine
- Dashboard

3.5 IMPORTANT DATA-SOURCE RULE
The Market Data Engine must use ONLY:
- MT5 / Exness real market data

It must NOT use:
- Yahoo Finance
- TradingView
- Alpha Vantage
- Fake data
- Demo/mock market data

IMPORTANT:
The Market Data Engine must be the SINGLE SOURCE OF TRUTH for market data.
